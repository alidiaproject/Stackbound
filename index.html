Rules & assumptions

Firebase multiplayer

Firebase connection is included, but you must supply your own Firebase web app configuration, enable Anonymous Authentication, and create a Firestore database. This prototype uses direct Firestore transactions. It is suitable for friendly testing, not cheat-resistant competitive play.

Share the room ID with a friend. Both players must use this page hosted on HTTPS. The game opens in the Play tab once connected. Room state is synchronized, but opponents' hands are not encrypted in Firestore.
